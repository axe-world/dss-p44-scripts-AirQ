Integration von AirQ Luftqualitätsmessgerät in Digitalstrom. Stellt DS die folgenden Sensordaten vom AirQ zur Verfügung: 

CO2, CO, Temperatur, Lautstärke, Feuchtigkeit, Luftdruck, Feinstaub PM1, Feinstaub PM2.5, Feinstaub PM10

Für O2, NO2, O3 hat Digitalstrom leider keine passenden Sensoren /Einheiten.

Im implementation Script muss die IP des AirQ und das eigene Passwort eingetragen werden.
